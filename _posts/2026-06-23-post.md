2026年初，由连续创业者姚颂、著名跨国产业集团正大集团、清华知名青年学者于超联合发起，以“用物理智能给世界带来便利”为使命，正行创新（Striding AI）悄然成立。

正行创新致力于探索物理智能的技术边界，通过世界动作模型与强化学习技术，推动将人形机器人大规模部署至真实商业与工业场景，成为全球可信赖的机器人服务提供商。

公司现已完成近亿美元天使轮系列融资，投资方包括正大集团、华勤技术、九安医疗等多家上市企业、多位国内与世界知名企业家，以及多家一线投资机构。

# 顶尖团队，从“脑”到“体”的全栈能力

物理智能既是一场算法革命，也是一场系统工程的硬仗，对团队的技术创新能力和产业经验提出了极高要求。

公司创始人兼 CEO 姚颂，是国内硬科技领域少有的跨行业连续成功创业者。他曾联合创立 AI 芯片公司深鉴科技并任 CEO，带领公司研发高能效 AI 芯片，在辅助驾驶、智慧城市等领域取得突破。2020 年，姚颂再次作为联合创始人与联席 CEO 创立东方空间，创造了全球最大固体运载火箭等多项商业航天纪录。从 AI 芯片到商业航天、再到物理智能，姚颂始终在做同一件事——把前沿技术真正带入产业。

联合发起人于超博士，现任清华大学深圳国际研究生院助理教授、博士生导师，长期深耕强化学习与机器人研究，师从清华大学汪玉教授，与姚颂有着同门默契。她主导提出的多智能体强化学习算法 MAPPO 已成为领域基准方法；团队开发的具身智能训练框架 RLinf 开源半年即获 3800+ GitHub Star，被海内外多家顶尖高校与头部机器人、AI Infra 企业采用。近年来，于超团队持续推进世界模型驱动的机器人训练、真实机器人在线学习、VLA 强化学习后训练等方向，形成从算法、系统到机器人应用的完整技术积累。

正行创新已组建一支资深的全栈研发团队，成员毕业于清华、上海交大、中科大、华中科大、哈工大等国内顶尖高校，并拥有蔚来、智元、海康、大疆、主线等头部企业的研发与产品化经验，能力覆盖基座模型、强化学习、具身智能体系统、运动控制、人机交互、嵌入式软件、人形机器人整机设计、场景解决方案以及大规模量产交付等关键环节。

我们深信，物理智能的长期竞争力，不只来自某个单点的技术突破，更来自将算法、软件、硬件、数据与场景整合为一个持续进化系统的组织能力。

# 数据、模型与 Infra，构建物理智能的系统性竞争力

我们认为，物理智能的“智能”突破，不能仅依靠单一算法或单独硬件的推进，而是来自基于真实场景的数据、算法与 Infra（基础设施）的共同进化。

正行创新将真实场景作为技术路线的起点，依托于战略伙伴的真实门店、产线与服务场景，推进百万小时级真实世界数据采集。这些环境中天然存在的复杂变化与长尾问题，正是训练可用、稳定、可泛化机器人的关键来源。

在模型层面，正行创新与清华大学团队联合开发新一代机器人基座模型。真正的物理智能模型，不应执着于每一个像素的生成，而应在一个可实时处理的模型中，学习基础物理法则和物理常识。基于这一判断，团队已完成“隐空间世界动作模型”的阶段性验证，让机器人在更高效的隐空间中学习物理状态变化，推动人类动作与机器人动作的对齐迁移，使机器人能从海量人类视频中习得通用动作规律，减少对昂贵遥操作数据的单一依赖。

此外，正行创新正在构建面向真实场景的具身智能体系统，通过“感知—规划—执行—反馈—恢复”的 Agent Loop（智能体循环），将单点操作能力组织为场景级长流程任务的稳定执行能力。同时进一步推进“Human-in-the-Loop（人在环路）”的强化学习后训练与数据闭环建设。真实运行数据往往同时包含成功、失败、接管和低效行为，团队相关方法可以识别其中真正推动任务完成的高价值动作，并将交互数据转化为模型持续优化的训练数据。在真实机器人任务中，该方向已将任务成功率最高提升3倍，极大促进机器人迈入真实场景的工作应用。

然而，无论是海量数据的处理、复杂模型的训练，还是 Agent 的快速迭代，背后都极度依赖坚实的系统工程支撑。我们判断，不具备 Infra（基础设施）能力的公司，很难最终成为领先的物理智能公司。
围绕 Infra 层面，公司将与伙伴联合研究，建设面向机器人预训练、大规模强化学习与端云协同部署的系统基础设施，通过更高效的数据处理、训练调度与仿真评测等，持续降低机器人智能能力迭代所需的算力与时间成本。

# 深入结合场景，跑通真实数据—模型—应用飞轮

正行创新与跨国产业巨擘并肩，以全球市场为舞台，坚持以真实场景牵引技术创新。公司发起方之一的正大集团，是亚洲最具代表性的跨国企业集团,也是中国改革开放后获得“0001 号”批文的外商投资企业，业务横跨零售、农业与食品、批发与商超、电信与数字业务等多个领域，遍及全球20多个国家和地区，为正行创新提供了得天独厚的真实商业场景资源，并为公司重点开展出海业务提供独有的全球产业网络支持。

公司重要股东华勤技术，是全球领先、技术驱动的智能产品平台型公司，产品涵盖移动终端、计算及数据中心、AIoT和机器人等创新领域产品服务，拥有全球化的研发与制造能力，这为正行创新提供了真实的工业场景。

依托伙伴的产业资源，面向消费零售与工业制造两大方向，正行创新正同步研发轮臂机器人与人形机器人的本体及解决方案，重点面向劳动力紧缺、用工成本高昂的海外市场，及国内的真实场景示范应用，辅助员工进行高频繁重工作。首批自研本体与解决方案，将于下半年与大家正式见面。

走向通用具身智能绝非一日之功。在真实场景中我们积累的每一项基础能力，无论是任意物体的抓取、货架的精准识别，还是复杂流程的自主规划，都是未来家庭与生活通用场景中不可或缺的能力模块。我们将与重要合作伙伴紧密协作，共同构建对物理智能企业至关重要的“场景—数据—模型—产品—解决方案—场景”的完整闭环。对我们而言，通用是终局，通往通用的路上，每一个关键节点都能转化为真实的生产力与商业价值。

回望大模型时代，有三个关键时刻已经出现：GPT-3.5 的出现，让世界看到大模型技术切实可行；DeepSeek 的开源与免费使用，让大众真正接触并认可了这一技术趋势；而 Claude Code 的问世与实现数百亿美元的年营收，则向所有人证明了大模型巨大的商业价值。

这恰好对应正行创新所追求的——探索物理智能的技术边界、让人形机器人在真实场景中大规模落地、以及成为一家伟大企业。让我们一起成为这三个重要时刻的推动者与见证者，让物理智能真正走入千行百业与千家万户。
