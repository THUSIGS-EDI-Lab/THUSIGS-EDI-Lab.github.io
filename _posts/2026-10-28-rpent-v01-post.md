---
title: "RPent v0.1 发布：构建面向物理世界的具身智能体统一基础设施"
date: 2026-10-28
---

随着具身智能技术持续发展，机器人走向自主理解任务并执行复杂操作。

在这过程中，通用大模型负责理解目标、拆解任务和制定计划，VLA 等专家模型负责将决策转化为精细动作，感知与反馈机制帮助机器人根据环境变化调整执行策略，记忆系统积累并复用成功经验。如何统一连接不同模型、工具与机器人，形成统一、可扩展的任务执行闭环，成为具身智能系统发展的重要课题。

**由无问芯穹、清华大学、正行创新联合开源的具身智能体基础设施 RPent（Recursive Physical Agent），正式发布 v0.1 版本。RPent 通过开放式模块化架构与统一工具接口，构建覆盖任务规划、物理执行、环境反馈和经验复用的完整链路。v0.1 版本进一步开放多模型、多仿真环境与真机平台接入能力**，支持使用 Codex、Claude Code 等 Agent Harness 进行任务规划，并提供 Memory、Flash Mode、交互式 CLI 与 Web Dashboard，**形成可运行、可评测、可扩展的具身智能体基础设施。**

在实际验证中，RPent v0.1 在双臂 Franka、YAM 等真实机器人平台上完成餐具整理、物体操作、视觉识别与分类收纳等任务。在公开基准评测中，基于 GPT-6 Astra 在 LIBERO-PRO 上达到 **92.63% 的任务成功率**；通过 Flash Mode 复用成功任务流程，在 LIBERO-PRO 评测中实现约 **6.8 倍执行加速**。
